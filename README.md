# موقع معلم ديكورات الرياض — نسخة GitHub Pages

هذه نسخة **واجهة ثابتة** من موقع ديكور المنزل، منشورة عبر GitHub Pages على النطاق المخصص `decor24.lol`. تم الحفاظ على تصميم الواجهة، النصوص، صفحات الخدمات العربية، بيانات SEO، ملفات `robots.txt` و`sitemap.xml`، والصور المحلية المستخدمة في المشروع.

## المسارات المحفوظة

- `/`
- `/معلم-دهانات-الرياض`
- `/معلم-جبس-بورد-الرياض`
- `/معلم-ترميم-الرياض`
- `/معلم-بديل-الرخام-والخشب-الرياض`
- `/معلم-ورق-جدران-الرياض`
- `/معلم-شيبورد-وتكسيات-الرياض`
- `/login`
- `/admin`
- `/404`

ملف `404.html` نسخة من الصفحة الرئيسية حتى تعمل الروابط العربية عند فتحها مباشرة من Google أو من إعلان. هذه النسخة الثابتة لا تشغّل خادم Node/MySQL أو tRPC؛ لذلك تبقى التقييمات ولوحة الإدارة متاحة فقط على نسخة Manus الأصلية إلى أن يتم توفير Backend منفصل.
